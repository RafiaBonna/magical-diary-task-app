# 📖 Magical Diary Task App (Immersive & Gamified)

An enchanting, fairy-tale-themed task management web application powered by a Laravel backend. Designed as an interactive royal diary, this app transforms everyday to-dos into a magical experience featuring 3D page-flip animations, dynamic butterfly flights, particle sparkle effects, and immersive audio cues.

## ✨ Enchanting Features
* **📖 3D Page-Flip Effect:** Interactive book cover and pages built with advanced CSS 3D Transforms (`rotateY`).
* **🦋 Dynamic Butterfly Animation:** SVG-based magical butterfly flight paths that guide users across the diary.
* **✨ Particle & Sparkle Effects:** Canvas-based dynamic starbursts triggered when tasks are completed or vanished.
* **🎵 Magical Sound Effects:** Integrated Web Audio API delivering whimsical chimes and whooshes.
* **🔒 Secure Laravel Backend:** Robust API and backend architecture built with Laravel to handle task data securely.
* **📱 Responsive Kingdom:** Seamlessly optimized for mobile, tablet, and desktop screens.

---

## 🎨 Tech Stack
* **Backend:** Laravel (PHP), MySQL / Database Migrations
* **Frontend:** React.js, HTML5, Pure CSS3 (3D Transforms, Custom Keyframes), JavaScript (ES6+, Audio API, Canvas Particles)
